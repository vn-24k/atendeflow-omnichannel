Demonstração do Widget Embeddable AtendeFlow

Esta página simula uma landing page ou portal corporativo de terceiros. O widget flutuante no canto inferior direito está conectado em tempo real à API REST e ao Banco de Dados SQLite do AtendeFlow.

Para embutir o widget em qualquer loja Shopify, WordPress ou landing page, basta colar o código abaixo antes do fechamento da tag </body>:

<script src="/widget.js" data-title="Suporte Oficial" data-primary-color="#4F46E5" async></script>

Abra o widget no canto inferior direito, digite uma mensagem e veja o ticket aparecer instantaneamente no painel do operador do AtendeFlow!
